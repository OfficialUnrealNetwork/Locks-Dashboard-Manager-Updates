## About

This repository is used to distribute public releases of **Lock Release / Locks Tracker**.

The main application source code is maintained privately in:

```text
Sault-Ste-Marie-Locks/Locks-Dashboard-Manager
```

This repository is intentionally kept minimal and contains only the files required for public downloads, application updates, and release distribution.

---

## Downloads

Windows and macOS installers are published through **GitHub Releases**.

Use the repository's **Releases** section to download:

* Windows installers
* macOS installers
* Application update packages
* Automatic-update files
* Previous supported releases

For most users, the latest release is recommended.

---

## Automatic Updates

Lock Release uses this repository to distribute update packages to installed versions of the application.

Release files published here may be downloaded automatically by the application when a newer version becomes available.

Because this repository is part of the production update system, release files should not be renamed, removed, or modified after publication unless required for an update fix.

---

## Source Code

The Lock Release application source code is **not hosted in this repository**.

Development is maintained privately in:

```text
Sault-Ste-Marie-Locks/Locks-Dashboard-Manager
```

This separation keeps development files private while allowing installers and application updates to remain publicly accessible.

---

## Download Website

The `gh-pages` branch contains the public Lock Release download page.

It is kept separate from the release files and application source.
